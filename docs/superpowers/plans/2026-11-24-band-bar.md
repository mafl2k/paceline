# Band bar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Action (and Rest) window's power bar shows a 5 s band and the 10 s average as its marker instead of the old filtered marker, with an optional numbers row.

**Architecture:** A new pure engine module `pages/src/engine/powerband.mjs` (tested with `node --test`) replaces the marker filter in `display.mjs`. `paceline.mjs` feeds it one sample per second with the phase (pull or READY) and renders band, marker and numbers into the existing bar markup. A per-window Sauce setting `barNums` switches the numbers.

**Tech Stack:** Plain ES modules, Sauce for Zwift mod pages, `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-24-band-bar-design.md`. Reference implementation of the
engine: branch `bar-workout`, `pages/src/engine/barfilters.mjs` (`bandStep`) and the band/number CSS
in its `pages/css/paceline.css` (`.pl-bar-band`, `.pl-bar-num`, `.pl-num-lo`, `.pl-num-hi`); read it
with `git -C /Users/mafl/Development/sauce/paceline-bar-workout show HEAD:<path>`.

### Task 1: The band engine

**Files:**
- Create: `pages/src/engine/powerband.mjs`
- Create: `tests/powerband.test.mjs` (add to `package.json` test list)

**Interfaces:**
- Produces:
  - constants above, exported.
  - `zoneWithHysteresis(w: number, target: number, prev: 'green'|'amber'|'red'|null): 'green'|'amber'|'red'` (from `bar-workout`'s `display.mjs`, uses `GREEN_PCT`/`AMBER_PCT`).
  - `bandStep(st: object|null, {at: ms, w: watts, goal: watts|null, since: ms, neutral: boolean}): object` returning `{since, at, ..., w, snap, mean, lo, hi, marker, zone}`. `w` = de-spiked power (median of the last 3 raw samples). `snap` runs from the first sample of the phase: first value = `w`; then if `|w - ema| > SNAP_PCT % of goal` (of `w` itself without a goal) `ema = w`, else `ema += (w - ema) / SNAP_TAU_S`; `snap` = `ema` through the `LP_TAU_S` lowpass (first value unfiltered). The window (`hist`, `AVG_S` long) starts `AVG_PREFILL_S` after `since`, filled with the median of the raw samples from `AVG_FROM_S` on (as `bar-workout`'s `bandStep`), then takes `w` each second; `mean` = its average (null before). `lo/hi` run from the first sample of the phase: `BAND_LO_PCT/BAND_HI_PCT` percentiles of the real de-spiked `w` of the phase's last `BAND_S` seconds (never the prefill), through the `LP_TAU_S` lowpass (first value unfiltered). `marker` = `mean ?? snap`. `zone` = `zoneWithHysteresis(mean, goal, prev)` when `mean` runs, a goal > 0 and not `neutral`, else null. Starts over when `since` changes or the last sample is more than `POWER_KEEP_MS` (`display.mjs`) old. Non-finite `w` returns `st` unchanged.
  - `bandFresh(st, now): object|null` — `st` if it has a `marker` and its last sample is at most `POWER_KEEP_MS` old, else null.
  - `bandNumbers(goalW: number, {kg: number|null, unit: 'W'|'Wkg'}): string[]` — the four edges at `-AMBER_PCT, -GREEN_PCT, +GREEN_PCT, +AMBER_PCT` of `goalW`: `unit 'W'` (or no kg) → watts rounded to 10 (`'180'`); `'Wkg'` with kg → `edgeW / kg` rounded to 0.1 with one decimal (`'2.7'`).
